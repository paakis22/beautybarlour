# BeautyBarlour

BeautyBarlour is a beauty shop UI/UX design concept that allows users to view available services, menu options, pricing details, and a gallery of beauty works.  
This project focuses on creating a clean, modern, and user-friendly interface for a beauty salon website.

---

## 🎨 Features

- View beauty services offered by the salon  
- Service menu with pricing details  
- Image gallery showcasing salon work  
- Clean and responsive UI design  
- User-friendly layout and navigation
